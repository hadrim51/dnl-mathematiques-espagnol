1.3. Obstáculos didácticos y controles

Símbolo y nivel

Un mismo signo no representa el mismo valor si cambia de nivel. El control consiste en escribir el multiplicador del nivel antes de calcular.

Cero posicional

La concha conserva un nivel nulo. Si un nivel vale cero, se escribe y se conserva en la recomposición.

Base 20 y calendario

La base 20 regular usa 1, 20 y 400. Las unidades calendáricas se estudian aparte para evitar confusiones.

Verificación

Una conversión se valida con una igualdad: a×400 + b×20 + c = N, o a×20 + b = N.

3.2. Base 20 regular

N = a × 20 + b para dos niveles
N = a × 400 + b × 20 + c para tres niveles

Las cifras de cada nivel deben estar entre 0 y 19. El nivel inferior representa unidades; el siguiente, veintenas; el siguiente, grupos de cuatrocientos.

3.3. Cero posicional

El cero permite conservar una posición vacía. Sin cero, una escritura vertical puede volverse ambigua.

Frase clave: “La concha indica que este nivel vale cero; por eso la posición se conserva.”

3.4. Calendario y precaución

En la Cuenta Larga aparecen unidades calendáricas específicas. No hay que confundir un modelo vigesimal regular con una información de calendario.

Criterio de logro observable: convierto en ambos sentidos un número de dos niveles, conservo los niveles que valen cero y compruebo la recomposición.

3.5. Herramientas matemáticas de Seconde

Potencias de 20

Cada nivel regular multiplica el valor por 20. Los pesos sucesivos son 20⁰ = 1, 20¹ = 20, 20² = 400 y 20³ = 8000.

División euclídea

Para convertir un entero decimal, se divide sucesivamente por 20. Cada resto es una cifra vigesimal y debe cumplir 0 ≤ resto < 20.

N = 20q + r, con 0 ≤ r < 20

Algoritmo de conversión

  1. Divide entre 20.
  2. Conserva el resto.
  3. Repite con el cociente.
  4. Lee los restos del último al primero.
  5. Verifica por recomposición.

Estimación y control

Antes de calcular, localiza el intervalo: dos niveles representan hasta 20²−1; tres niveles representan hasta 20³−1. Después comprueba que cada cifra esté entre 0 y 19.

7. Procedimientos matemáticos

Método 1 · Leer una cifra maya

  1. Cuento barras.
  2. Multiplico las barras por 5.
  3. Cuento puntos.
  4. Sumo barras y puntos.
  5. Si hay concha, el valor del nivel es 0.

Método 2 · Convertir base 10 → base 20

  1. Busco el mayor nivel útil.
  2. Divido por el valor del nivel.
  3. Conservo cociente y resto.
  4. Repito con el nivel siguiente.
  5. Represento cada cifra con puntos, barras o concha.

Método 3 · Convertir base 20 → base 10

  1. Leo cada nivel de abajo hacia arriba.
  2. Asocio un multiplicador a cada nivel.
  3. Escribo la suma.
  4. Calculo y verifico.

Método 4 · Argumentar

  1. Identifico la regla usada.
  2. Escribo la descomposición.
  3. Explico el cero si aparece.
  4. Concluyo con una frase clara.

7.1. Errores frecuentes

  • Confundir punto y barra.
  • Leer los niveles de arriba hacia abajo sin comprobar la convención.
  • Olvidar la concha en un nivel vacío.
  • Usar la regla del calendario en un ejercicio de base 20 regular.
  • Dar una respuesta sin descomposición ni verificación.

10. Preparación de la evidencia

Organiza una escritura maya, una conversión anotada, una comprobación y una explicación breve.

Regla 1 — Valor de un nivel

  • En un nivel: valor = 5×(nº de barras) + 1×(nº de puntos).
  • Concha = 0 (nivel vacío).
  • En numeración regular, cada nivel está entre 0 y 19.

Regla 2 — Dos niveles

  • N = a×20 + b, con 0 ≤ a,b ≤ 19.
  • a = número de veintenas; b = unidades.
  • Verifico recomponiendo la suma.

Regla 3 — Tres niveles

  • N = a×400 + b×20 + c, con 0 ≤ a,b,c ≤ 19.
  • 400 = 20×20: tercer nivel.
  • Si b o c = 0, debo escribir la concha en ese nivel.

Lista de control rápida

  • ¿He leído de abajo hacia arriba?
  • ¿Cada cifra está entre 0 y 19?
  • ¿He conservado los ceros con concha?
  • ¿Tengo una igualdad de verificación?

Aplicaciones del método

Aplicación A: para convertir 54, divide entre 20. Conserva el cociente para el nivel superior y el resto para el nivel inferior; termina con una igualdad de verificación.
Aplicación B: para leer dos niveles, llama a la cifra superior a y a la inferior b; escribe primero a×20+b antes de efectuar el cálculo.
Aplicación C: si un número tiene tres niveles y el nivel central está vacío, se conserva la concha y se escribe a×400+0×20+c.

¿Qué método elijo?

  • Un solo nivel: cuento barras y puntos.
  • Dos niveles: uso a×20+b.
  • Tres niveles: uso a×400+b×20+c.
  • Una posición vacía: escribo 0 y conservo el nivel.

Control de resultado

  • Cada cifra debe estar entre 0 y 19.
  • El resto de una división por 20 debe ser inferior a 20.
  • La recomposición debe devolver el número inicial.
  • La regla calendárica no se aplica automáticamente a la numeración regular.
