1. Competencias dominantes de la sesión

La sesión moviliza principalmente C2, C3, C4 y C6: leer sistemas, comprobar ejemplos, comparar con un criterio común, responder a una objeción y reformular en español.

Referencia cultural

Relacionar cada sistema con su contexto, su soporte y sus usos, sin confundir hecho histórico y descripción matemática actual.

C2 · Leer y representar sistemas

Leer una representación e identificar símbolos, base, cero, soporte y regla de escritura.

C3 · Calcular, convertir y verificar

Calcular, convertir y comprobar un ejemplo numérico antes de usarlo como prueba.

C4 · Comparar y argumentar

Aplicar el mismo criterio a varios sistemas, defender una afirmación y reconocer un límite.

Producción

Organizar una tarjeta de argumento con afirmación, ejemplo comprobado y límite reconocido.

C6 · Mediar y evaluar

Escuchar, reformular, responder a una objeción y evaluar con criterios compartidos.

2. Ruta de aprendizaje de la sesión 3 · 60 minutos

La sesión avanza del cálculo comprobado al criterio, del criterio al argumento y del argumento a una conclusión matizada.

Requisitos previos

Leer una representación sencilla, descomponer un entero y producir una frase comparativa en español.

Diagnóstico · 5 min

Representa 33 en dos sistemas y comprueba que ambas escrituras corresponden a la misma cantidad.

Objetivo lingüístico

Comparar y matizar con «Según el criterio de…», «Sin embargo…» y «Depende del uso porque…».

2.2. Obstáculos didácticos y controles

Comparar sin criterio

Una opinión no es un argumento. El control consiste en anunciar el criterio antes del ejemplo.

Ejemplo no verificado

Cada argumento debe contener una conversión, una descomposición o una comparación de longitud verificable.

Ganador absoluto

La conclusión debe precisar el contexto: cálculo, memoria, administración, legibilidad, soporte o mediación.

Confundir cultura y matemáticas

Se analiza una propiedad del sistema o un uso, nunca una cultura.

2.3. Rutina común del debate

  1. Observar: identificar el sistema, la base, el cero, el soporte o la regla de escritura.
  2. Modelizar: elegir un número común o una tarea precisa.
  3. Verificar: producir una prueba matemática breve y verificable.
  4. Argumentar: formular una tesis con un criterio y un límite.
  5. Reformular: responder a una objeción sin negar el contexto.

3. Conceptos matemáticos esenciales

Número y numeral

El número es la cantidad; el numeral es la escritura de esa cantidad en un sistema dado.

Base

La base indica el tamaño de los grupos. En base b, las posiciones valen potencias de b.

Valor posicional

Una misma cifra puede tener valores diferentes según su lugar.

Cero

Puede indicar ausencia de cantidad y también conservar una posición vacía.

Sistema aditivo

Los símbolos se suman para obtener la cantidad.

Sistema sustractivo

En algunos casos, un símbolo antes de otro resta valor.

En base b: N = aₙ×bⁿ + … + a₂×b² + a₁×b + a₀

3.1. Herramientas de Seconde

Escritura polinómica

En base b, un número de cuatro cifras se expresa como a₃×b³ + a₂×b² + a₁×b + a₀, con 0 ≤ aᵢ < b.

Conversión hacia base diez

Multiplica cada cifra por la potencia de la base que corresponde a su posición y suma los resultados parciales.

Conversión desde base diez

Realiza divisiones euclídeas sucesivas por la base. Conserva los restos y léelos del último al primero.

Control de validez

Comprueba que cada cifra sea menor que la base, que los restos sean válidos y que la recomposición devuelva el número inicial.

N = aₙbⁿ + … + a₂b² + a₁b + a₀

5. Convertir y comprobar

Base 10 → base b

  1. Dividir por la base.
  2. Conservar el resto.
  3. Repetir con el cociente.
  4. Leer los restos en orden inverso.
  5. Verificar recomponiendo.

Base b → base 10

  1. Identificar posiciones.
  2. Multiplicar cada cifra por una potencia de la base.
  3. Sumar los términos.
  4. Comprobar la coherencia.

Sistema aditivo

  1. Identificar símbolos.
  2. Aplicar suma o resta según la regla.
  3. Reconocer limitaciones para operaciones.

Registro material

  1. Identificar soporte.
  2. Localizar posiciones o categorías.
  3. Interpretar según convención.
  4. Reconocer el papel del contexto.
Atención: aplica cada método a un ejemplo propio y termina con una igualdad de comprobación.

7. Del ejemplo al argumento

Tesis

“Según el criterio de ___, el sistema ___ es pertinente porque ___.”

Ejemplo verificable

“Lo verifico con una descomposición / una conversión / una comparación de símbolos.”

Límite

“Sin embargo, este sistema es menos adecuado para ___.”

Conclusión matizada

“Por lo tanto, en el contexto ___, este sistema resulta más útil que ___.”

8. Argumentar y reformular en español

Argumento completo

Defiendo el sistema ___. Mi criterio es ___. Lo justifico porque ___. Un límite es ___.

Contraargumento

“Entiendo tu idea; sin embargo, con el criterio de ___ aparece el problema de ___.”

Voto justificado

“Voto por ___ en el contexto de ___, porque ___; aun así, reconozco que ___.”

Comparación prudente

“No hay un sistema mejor para todo: depende del uso, del soporte y del tipo de cálculo.”

9. Preparar la tarjeta de argumento

Resumen operativo para representar, convertir, verificar y transformar un resultado en una prueba para el debate.

Regla A — Escritura en base b

  • En base b: N = aₙ·bⁿ + … + a₁·b + a₀ (0 ≤ aᵢ < b).
  • La posición cambia el valor: misma cifra ≠ mismo valor.
  • Cero: marca ausencia y conserva la posición.

Método 1 — 10 → base b (cociente/resto)

  • Divido por b: guardo el resto.
  • Repito con el cociente hasta llegar a 0.
  • Leo los restos al revés y verifico recomponiendo.

Método 2 — base b → 10 (recomposición)

  • Identifico posiciones (potencias de b).
  • Multiplico cada cifra por su potencia.
  • Sumo y compruebo la coherencia.

Lista de control de argumento

  • ¿Mi criterio es matemático y está definido?
  • ¿Incluyo un ejemplo numérico verificable?
  • ¿Reconozco un límite o contexto?
  • ¿Concluyo sin decir “mejor para todo”?

Aplicaciones del método

Aplicación A · Recomponer

En base 5, una escritura de tres cifras se interpreta como a×5²+b×5+c. Antes de calcular, comprueba que cada cifra sea inferior a 5.

Aplicación B · Convertir

Para convertir un entero decimal a base 4, divide sucesivamente por 4, conserva cada resto y léelos desde la última división hacia la primera.

Aplicación C · Comparar

Compara dos sistemas con el mismo número y el mismo criterio: longitud de escritura, presencia de cero, facilidad de cálculo o necesidad de un soporte material.

Aplicación D · Verificar

Haz el camino inverso: después de convertir, recompón en base 10. Si recuperas el número inicial, la conversión es coherente.
