4. Transformaciones

Traslación

Todos los puntos se desplazan con el mismo vector. La comprobación consiste en comparar dos puntos correspondientes.

Vector u = (a; b)

Giro o rotación

Una figura gira alrededor de un centro. La comprobación necesita centro, ángulo y superposición.

Ángulo mínimo = 360° ÷ orden

Simetría axial

Una recta funciona como espejo. La comprobación compara puntos a igual distancia del eje.

Reflexión deslizante

Reflexión seguida de una traslación paralela al eje. Se observa solo en ejemplos guiados de profundización.

5. Motivo, tesela y unidad de repetición

Un motivo periódico se estudia separando tres objetos: el dibujo visible, la pieza o tesela posible y la unidad elegida para describir la repetición. No siempre coinciden.

Motivo

Parte visible que se repite o parece repetirse.

Tesela

Pieza geométrica que podría recubrir el plano, si la actividad estudia un pavimento.

Unidad de repetición

Parte elegida para reconstruir el patrón mediante traslaciones.

Verificación

  • ¿Dos vectores son independientes?
  • ¿El color se conserva?
  • ¿La imagen completa permite concluir o solo proponer?

7. Comprobar una hipótesis

Calco

Permite superponer una copia del motivo después de una traslación o un giro. Si el conjunto coincide, la hipótesis se refuerza.

Espejo

Sirve para una simetría axial. El eje debe dejar el patrón en correspondencia.

Cuadrícula

Permite controlar vectores, distancias y posiciones correspondientes.

P' = P + u

Medida

Controla una distancia, un ángulo o una igualdad necesaria.

Color

Una transformación es simetría del patrón coloreado si conserva también el color correspondiente.

Conclusión prudente

Se distingue lo comprobado en el fragmento observado de la clasificación completa del patrón.

8. Procedimientos

Procedimientos para pasar de una observación a una justificación clara en español.

Analizar una traslación

  1. Elige un punto reconocible.
  2. Busca su copia.
  3. Traza el vector.
  4. Comprueba la misma dirección y distancia en otro punto.

Analizar un giro

  1. Localiza un centro posible.
  2. Estima el ángulo.
  3. Comprueba la superposición con calco.
  4. Verifica si el color también coincide.

Analizar una simetría axial

  1. Traza un eje candidato.
  2. Compara puntos correspondientes.
  3. Usa espejo o calco.
  4. Limita la conclusión si un detalle o un color no coincide.

Formular la tarjeta

  1. Nombre de la transformación.
  2. Elemento característico.
  3. Herramienta de comprobación.
  4. Frase con «porque».

9. Árbol de decisión simplificado

  1. ¿Hay una repetición por traslación? Busco un vector entre dos copias.
  2. ¿Hay un centro de giro? Pruebo 180°, 120°, 90° o 60°.
  3. ¿Hay un eje? Compruebo con espejo, calco o puntos correspondientes.
  4. ¿El color y los detalles se conservan? Si no, la simetría de la forma puede no ser la del motivo coloreado.
  5. ¿La imagen es completa? Si no, formulo una hipótesis, no una clasificación definitiva.
Frase modelo: « Observo… Lo compruebo con… Por eso, mi hipótesis es… porque… »

14.4. Color y percepción

14.4. Color y percepción

Un mismo diseño puede tener más simetrías si ignoramos los colores que si los consideramos. En un patrón coloreado, la transformación debe conservar forma y color.

El color puede modificar el conjunto de simetrías que conserva un motivo.
Actividad DNL: Analiza primero la forma y después el patrón coloreado.

Forma

Puede conservarse aunque cambie el color.

Color

Si el color cambia, la simetría puede no ser válida para el patrón coloreado.
