5. Método

  1. Observo: identifico formas, colores, materiales, módulos y repeticiones visibles.
  2. Selecciono: elijo una unidad de repetición y explico qué parte de la fuente dejo fuera del modelo.
  3. Construyo: uso medidas, coordenadas o restricciones simples para producir una unidad digital.
  4. Duplico: aplico una transformación exacta y registro el vector, el centro o el eje si procede.
  5. Compruebo: longitudes, ángulos, alineaciones y propiedades conservadas.
  6. Comparo: separo fuente patrimonial, modelo simplificado, reconstrucción y variación asumida.
  7. Redacto: una leyenda con fuente de inspiración, medida, transformación, propiedad conservada y diferencia asumida.

6. Unidad de repetición

La unidad de repetición es una construcción geométrica elegida para el modelo. Debe poder duplicarse exactamente sin presentarse como reproducción histórica.

Fuente patrimonial

Fotografía, monumento o detalle observado. Puede contener irregularidades, relieve, desgaste, material y contexto.

Modelo simplificado

Conjunto de formas, medidas y restricciones elegidas para estudiar una organización geométrica.

Reconstrucción digital

Producción construida con una herramienta. Debe indicar qué conserva y qué simplifica.

Variación asumida

Modificación deliberada de color, escala, detalle o composición, indicada como tal.

7. Medidas y restricciones

Las medidas y restricciones sirven para construir y comprobar la unidad digital: longitudes, ángulos, alineaciones, escala y encaje.

Criterio local: ángulo 1 + ángulo 2 + ... + ángulo k = 360°
Atención: una suma de 360° verifica un cierre local en un vértice. La reconstrucción completa exige también comprobar la repetición, el encaje y las propiedades conservadas por la transformación.
Control de modelo: una medida exacta en la reconstrucción no demuestra una reproducción histórica; demuestra que la regla matemática elegida es coherente.

8. Duplicación exacta

Traslación

Desplaza la unidad sin girarla. Se describe mediante un vector y conserva longitudes, ángulos y alineaciones.

Rotación

Gira alrededor de un centro. Se usa si centro, ángulo y superposición son explícitos.

Simetría axial

Un eje funciona como espejo. Puede servir para analizar o completar un motivo si la correspondencia es verificable.

Composición

Si se encadenan transformaciones, se registra cada etapa y se comprueba la propiedad conservada.

Leyenda de la captura

  1. Fuente de inspiración.
  2. Unidad de repetición construida.
  3. Transformación usada.
  4. Propiedad conservada.
  5. Variación o simplificación asumida.

Errores frecuentes

  • Confundir la fotografía con el modelo.
  • Duplicar sin indicar la transformación.
  • Modificar colores sin explicarlo.
  • Presentar una reconstrucción como reproducción exacta.

11.5. Arte, color y ritmo visual

11.5. Arte, color y ritmo visual

El color y el ritmo visual pueden conservar o modificar la lectura de una repetición.
Actividad DNL: Comprueba si el color conserva la repetición o la simetría.

El rojo del ladrillo, el brillo cerámico y la repetición de piezas producen una lectura rítmica. El color puede ayudar a identificar módulos, pero también modificar la percepción de una simetría.

Material

El ladrillo aporta módulo, textura y color.

Ritmo

La repetición organiza la mirada y guía el recorrido.

Escala

Un motivo pequeño crea textura; uno grande estructura el espacio.
