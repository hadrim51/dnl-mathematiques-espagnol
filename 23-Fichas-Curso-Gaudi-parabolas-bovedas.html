Recorrido esencial: un modelo principal correctamente comprobado. Los la ecuación de la catenaria y la validación estructural quedan fuera de lo exigible; funciones cuadráticas, sucesiones y restricciones se trabajan de forma guiada.

1. Competencias de la sesión

La sesión 3 parte de una curva observada, recoge puntos en un sistema de coordenadas, construye una tabla de valores, ajusta una parábola sencilla y compara el modelo con la catenaria como referencia cualitativa.

C1 · Observar

Localizar una curva, una clave aproximada, apoyos y un eje posible.

C2 · Recoger datos

Leer o proponer puntos en un sistema de coordenadas con unidades.

C3 · Calcular

Completar una tabla de valores y calcular parámetros de una parábola.

C4 · Modelizar

Usar una forma sencilla, como y = ax² + h, para aproximar una curva observable.

C5 · Comparar

Comparar el modelo con puntos observados y formular un dominio de validez.

C6 · Matizar

Distinguir parábola, catenaria y edificio real, sin confundir aproximación y igualdad.

Producción esperada: un croquis, una nube de puntos, una tabla de valores, una plantilla parabólica, una comparación y una frase de límite.

3. Método de ajuste parabólico

Rutina DNL

  1. Observo la curva y nombro el soporte de la imagen.
  2. Coloco un sistema de coordenadas simplificado.
  3. Recojo puntos, con incertidumbre si la lectura procede de una imagen.
  4. Elijo una forma de parábola adaptada a la pregunta.
  5. Calculo una tabla y un parámetro.
  6. Comparo el modelo con los puntos y enuncio sus límites.

Frases útiles

  • La parábola aproxima algunos puntos de la curva.
  • El vértice representa la altura máxima del modelo.
  • La catenaria corresponde a otro modelo.
  • El modelo es útil localmente, pero no es la curva exacta.
Precaución: una parábola puede servir como aproximación escolar. La catenaria se presenta aquí como comparación cualitativa, sin ecuación exigible.

4. Modelos de la sesión

4.1 Parábola simétrica

Si el eje de simetría es x = 0 y el vértice es V(0;h), se puede usar:

y = ax² + h

Si la curva se abre hacia abajo, entonces a < 0.

4.2 Usar un punto observado

Si un punto P(L;yP) pertenece al modelo, se sustituye en la ecuación.

yP = aL² + h, por tanto a = (yP − h) / L²

Si el apoyo está en el suelo, yP = 0.

4.3 Tabla de valores

La tabla permite visualizar la forma del modelo y comprobar la simetría.

si el modelo es y = ax² + h, entonces y(-x)=y(x)

4.4 Errores absolutos

Para comparar un modelo con medidas aproximadas, se calcula la diferencia.

error absoluto = |medida observada − valor del modelo|

4.5 Catenaria

La catenaria es la forma de una cadena suspendida. Se puede comparar con una parábola, pero no se identifica con ella.

parecido visual ≠ igualdad matemática

4.6 Dominio de validez

Un modelo puede ser útil en una zona de la imagen y menos pertinente en otras zonas.

El modelo vale para..., pero no permite afirmar que...

5. Procedimientos

Método A · Leer puntos

  1. Defino el origen y las unidades.
  2. Identifico el vértice o un punto alto.
  3. Leo puntos a izquierda y derecha.
  4. Anoto la incertidumbre de lectura.
  5. Evito afirmar una medida real si no hay escala.

Método B · Calcular a

  1. Elijo la forma y = ax² + h.
  2. Uso el vértice para conocer h.
  3. Sustituyo un punto P(L;yP).
  4. Resuelvo a = (yP − h)/L².
  5. Compruebo con un punto simétrico.

Método C · Completar una tabla

  1. Elijo valores de x.
  2. Calculo x².
  3. Multiplico por a.
  4. Añado h.
  5. Compruebo la simetría.

Método D · Comparar con la catenaria

  1. Nombrar la semejanza visual.
  2. Indicar que la catenaria es otro modelo.
  3. Explicar que su ecuación no se exige aquí.
  4. Explicar para qué sirve la parábola escolar.
  5. Concluir con prudencia.
