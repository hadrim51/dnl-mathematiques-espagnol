1. Competencias de la sesión

La sesión 4 transforma las observaciones de las sesiones anteriores en regla de crecimiento. El alumnado construye tablas de valores, compara diferencias y cocientes, traza un motivo controlado y formula una frase de prudencia sobre Fibonacci y la fuente histórica.

Frases útiles

  • La regla añade siempre la misma cantidad.
  • El radio se multiplica por el mismo factor.
  • La tabla permite comprobar la regla.
  • La semejanza visual no basta para afirmar una intención histórica.
Puente con sesiones anteriores: la recta, la parábola y la catenaria eran modelos de dirección o de curva. En esta sesión, el modelo principal es una regla de crecimiento que produce un motivo.

4. Modelos de crecimiento

4.1 Sucesión aritmética

El radio aumenta la misma cantidad en cada paso.

u_n=u_0+n·r

Control: las diferencias entre radios consecutivos son constantes.

4.2 Sucesión geométrica

El radio se multiplica por el mismo factor en cada paso.

v_n=v_0·q^n

Control: los cocientes entre radios consecutivos son constantes.

4.3 Tabla de valores

La tabla hace visible la regla antes de trazar el motivo.

n : 0, 1, 2, 3, 4
r : r0, ..., ..., ..., ...

4.4 Fibonacci con prudencia

La sucesión se obtiene sumando los dos términos anteriores.

1, 1, 2, 3, 5, 8, 13, 21...

Se usa como referencia cultural y numérica, no como prueba sin fuente.

4.5 Comparación con parábola y catenaria

Una parábola o una catenaria modeliza una curva continua. Una tabla de crecimiento modeliza una construcción paso a paso.

curva ajustada ≠ motivo generado por regla

4.6 Validación

Un modelo se valida comparando medidas esperadas y medidas observadas.

error absoluto = |medida observada − valor del modelo|

5. Procedimientos

Método A · Construir una tabla aditiva

  1. Escribo el valor inicial r0.
  2. Escribo el aumento d.
  3. Calculo u_n=u_0+n·r.
  4. Compruebo diferencias constantes.
  5. Indico la unidad.

Método B · Construir una tabla multiplicativa

  1. Escribo el valor inicial r0.
  2. Escribo el factor k.
  3. Calculo k^n con n pequeño.
  4. Multiplico por r0.
  5. Compruebo cocientes constantes.

Método C · Usar Fibonacci

  1. Escribo los dos Premières términos.
  2. Sumo los dos últimos.
  3. Completo la tabla.
  4. Calculo una razón si se pide.
  5. Redacto una frase prudente.

Método D · Trazar un motivo controlado

  1. Elijo centro y escala.
  2. Calculo radios o longitudes.
  3. Marco puntos por pasos.
  4. Uno o dibujo el motivo.
  5. Añado una leyenda con regla y límite.
