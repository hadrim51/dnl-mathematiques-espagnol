4. Herramientas matemáticas

Rutina común: dato → fórmula/modelo → cálculo con unidad → verificación → frase de interpretación musical.

Armónicos

Si la fundamental es f₀, el armónico n vale fₙ = n × f₀.

Período

Para una frecuencia f en Hz, el período en segundos es T = 1/f. Cuando f aumenta, T disminuye.

Porcentajes de amplitud

porcentaje = amplitud del parcial ÷ suma de amplitudes × 100.

Octavas

Una octava más alta multiplica la frecuencia por 2. Las octavas de f₀ son f₀, 2f₀, 4f₀, 8f₀...

Envolvente simplificada

Duración total = ataque + decaimiento + sostenimiento + relajación.

Centroide / media ponderada

C = (f₁A₁+f₂A₂+...)/(A₁+A₂+...). Un valor más alto suele indicar un sonido más brillante.

5. Modelo aditivo simplificado

La síntesis aditiva representa un sonido complejo como una suma de parciales. En esta ficha de segundo, cada parcial se describe con una frecuencia y una amplitud relativa.

sonido complejo = parcial 1 + parcial 2 + parcial 3 + …

Frecuencia

Indica cuántas vibraciones ocurren cada segundo. Se mide en Hz.

Amplitud

Indica el peso relativo de una onda. Cambiar amplitudes cambia el timbre.

Espectro

Representa qué frecuencias están presentes y con qué amplitud.

Timbre

Es el color sonoro que permite distinguir dos sonidos con la misma altura.

Límite importante: el modelo es útil para calcular y crear, pero no describe toda la música: faltan gesto, interpretación, contexto, espacio, escucha, intención artística y evolución real del sonido.

6. Procedimientos paso a paso

Método 1 · Calcular armónicos

  1. Identifico f₀.
  2. Elijo el número de armónico n.
  3. Calculo n × f₀.
  4. Escribo Hz.
  5. Interpreto el resultado.

Método 2 · Calcular un período

  1. Identifico f en Hz.
  2. Uso T = 1/f.
  3. Escribo segundos.
  4. Comparo: frecuencia mayor → período menor.

Método 3 · Porcentajes de amplitud

  1. Sumo todas las amplitudes.
  2. Divido cada amplitud por el total.
  3. Multiplico por 100.
  4. Identifico el parcial dominante.

Método 4 · Tabla de armónicos

  1. Creo columnas n y n·f₀.
  2. Calculo de n=1 a n=8.
  3. Busco las potencias de 2: 1, 2, 4, 8.
  4. Concluyo cuáles son octavas.

Método 5 · Envolvente

  1. Sumo ataque, decaimiento, sostenimiento y relajación.
  2. Calculo el porcentaje de una fase.
  3. Relaciono la duración con la percepción del sonido.

Método 6 · Media ponderada

  1. Multiplico cada frecuencia por su amplitud.
  2. Sumo los productos.
  3. Divido por la suma de amplitudes.
  4. Comparo los valores de C.
